sempre que alterar qualquer arquivo deste repositório, execute o fluxo completo de versionamento antes de encerrar a tarefa:
- revisar o estado do git
- fazer `git add` dos arquivos pertinentes
- criar `git commit` com mensagem coerente
- executar `git push` para o remoto configurado

não deixar alterações locais neste repositório sem commit e push, salvo se a usuária pedir explicitamente para não versionar ou não enviar ao GitHub
